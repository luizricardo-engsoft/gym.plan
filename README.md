## 🩸 Sobre o projeto

Projeto pessoal criado para organizar meu dia a dia de treino, dieta e rotina de manutenção de forma visual e prática.

A interface foi inspirada em estética dark/japonesa e em personagens fictícios, principalmente pela ideia de disciplina, constância e evolução física.

O objetivo não era criar algo profissional ou comercial, mas sim:

* deixar minha rotina mais organizada;
* transformar dieta e treino em algo mais visual;
* praticar front-end;
* criar um projeto pessoal estilizado.

# 🤖 Uso de IA

Este projeto foi desenvolvido praticamente por completo com auxílio de Inteligência Artificial, utilizando principalmente o Claude.

A IA foi responsável pela:

* estrutura do projeto;
* layout;
* estilização;
* organização visual;
* componentes;
* lógica em JavaScript;
* refinamento da interface.

O projeto foi criado como algo simples para uso pessoal no meu dia a dia, principalmente para organizar treino, dieta e rotina de manutenção de forma mais visual e motivadora.

A publicação no GitHub serve também como registro de aprendizado, experimentação com IA e exploração de design/front-end usando ferramentas modernas.
